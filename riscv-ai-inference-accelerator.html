AI Inference Accelerator on RISC-V with Custom Instructions

Edge devices need AI inference that is fast, small, and power-efficient. This project builds an AI inference accelerator engine on RISC-V: a unified Microscaling (MX) coprocessor attached to the core through the CV-X-IF coprocessor interface, so that MX-format tensor operations become custom instructions in the processor pipeline rather than calls to an external device. Software issues one instruction; the coprocessor performs the block-scaled arithmetic.

The accelerator supports the OCP Microscaling formats MXFP8, MXFP6, MXFP4, and MXINT8 in a single unified datapath, so the same hardware can run quantized neural network inference at different precision and efficiency points. The CV-X-IF approach keeps the base RISC-V core unmodified and standard-compliant. The accelerator logic sits behind a clean interface, which makes the design portable across CV-X-IF-capable cores and easy to extend with new formats.

What makes this inference engine different from a pure performance project is that it is built for security evaluation from the start. The design includes scan-chain observability into the coprocessor state, so every cycle of an inference computation can be inspected. That turns the accelerator into a research platform: the same engine that runs edge inference efficiently also serves as the measurement target for the microscaling fault analysis work, where fault injection reveals how MX number formats fail under attack.

The design philosophy, accelerating cryptographic or numerical kernels through RISC-V custom instructions while preserving observability, is shared with the openPQC accelerator for post-quantum cryptography. Both are part of a broader research program on secure, verifiable RISC-V accelerators, backed by two TSMC ASIC tape-outs (CAPRI1 and CAPRI6).
