Research

Fault Injection & Analysis

331 EMFI campaigns on RISC-V SoC. Direction-aware PDN loop models for fault susceptibility. EMFI, laser, and clock glitch attacks.

Microscaling (MX) Fault Analysis

Microscaling fault injection on OCP MX formats (MXFP8/6/4, MXINT8): one fault in a shared block scale factor corrupts a whole tensor. AIHWS and GLSVLSI 2026, both Best Paper Nominees. Read more

AI Inference Accelerator on RISC-V

AI inference engine built as a unified MX coprocessor on RISC-V, attached through CV-X-IF custom instructions, with scan-chain observability for security evaluation. Read more

Side-Channel Analysis

Differential and correlation power analysis on block ciphers (AES, PRINCE, SIMON, LED, GIFT), with countermeasure evaluation.

Pre-Silicon Models, Post-Silicon Validation

Leakage assessment using pre-silicon models, scan-chain-based micro-architecture state monitoring, and post-silicon validation of model predictions on TSMC test chips. Read more

Lightweight Cryptography

Secure implementation of lightweight ciphers for IoT and resource-constrained devices, including stream ciphers and block ciphers.

ML for Hardware Security

CNN/GNN-based fault detection achieving 92% accuracy. Transfer learning reducing SCA traces by 2.8× and test time by 30%.

Security Tools & Frameworks

Co-developer of SCAPEgoat, FaultDetective, and GlitchGlück toolchains for side-channel and fault security evaluation.

ASIC Design

Full RTL-to-GDSII flow. Led 2 tape-outs (CAPRI1, CAPRI6) in TSMC using Cadence, Synopsys, and OpenROAD.

Post-Quantum Cryptography

Accelerator-protected PQC on CV32E40X with a CV-X-IF coprocessor (openPQC): ML-KEM and ML-DSA custom instructions, protected and unprotected. First pre-silicon SCA methodology for ML-DSA-87: CPA with MTD=6 traces. Read more
