Microscaling (MX) Fault Analysis

Microscaling (MX) formats, standardized by the Open Compute Project (OCP), are block-scaled number formats such as MXFP8, MXFP6, MXFP4, and MXINT8. They cut the memory and energy cost of AI inference by letting a block of low-precision elements share one scale factor. Every major AI accelerator roadmap now includes them. What had not been studied before this work is how they behave when the hardware computing them is under attack.

This research line delivers the first microscaling fault injection study on real hardware. Using electromagnetic fault injection (EMFI) against a RISC-V edge platform executing MX-format inference workloads, it characterizes how each format family responds to injected faults. The central finding is an amplification effect: a single fault that lands in a shared block scale factor does not corrupt one value, it corrupts every element in the block, and the error propagates across the entire tensor. Formats that are equivalent in accuracy benchmarks are far from equivalent in fault robustness.

The evaluation platform is a RISC-V system-on-chip extended with a unified MX coprocessor through custom instructions, with scan-chain observability into the microarchitectural state. This makes fault effects visible at the exact cycle and register where they land, so faulty behavior can be traced from the physical injection down to the numerical error in the inference result. Machine-learning models (CNN and GNN) trained on scan-chain data classify faulty microarchitectural states automatically. The same platform is described on the AI inference accelerator page.

Why it matters: safety-critical edge AI (automotive, medical, industrial) is adopting MX formats for efficiency. This work gives hardware designers concrete, measured evidence of which formats and which microarchitectural choices amplify or contain faults, before those choices are frozen in silicon.
