Accelerator-Protected PQC: CV32E40X + CV-X-IF

Post-quantum cryptography is moving into products, but the implementations being deployed are hard to compare: every paper measures a different core, a different countermeasure, a different setup. openPQC addresses that with a single open platform: the CV32E40X RISC-V core extended through the CV-X-IF coprocessor interface with custom instructions that accelerate ML-KEM (FIPS 203) and ML-DSA (FIPS 204).

The platform is accelerator-protected: side-channel countermeasures live inside the coprocessor, next to the arithmetic they protect, instead of being patched into software after the fact. Each algorithm is available in both protected and unprotected variants on the same core, so the cost and the benefit of a countermeasure can be measured directly, on identical hardware, with nothing else changing. The CV-X-IF interface keeps the CV32E40X core itself unmodified, which makes the accelerator portable and the comparison clean.

The goal is an open-source reference for reproducible side-channel assessment of PQC standards. Anyone evaluating an ML-KEM or ML-DSA implementation can start from a known platform with known leakage behavior rather than building a target from scratch. The platform connects to the pre-silicon to post-silicon research line: leakage is assessed on pre-silicon models first, then validated on the physical implementation. Applied to ML-DSA-87, this top-down approach recovered key material with correlation power analysis at a minimum traces-to-disclosure of 6, and template attacks ranked the correct key in the top 10 within 50 traces.

openPQC is developed at the Vernam Lab, Worcester Polytechnic Institute, and released through the secure-Embedded-Systems GitHub organization.
