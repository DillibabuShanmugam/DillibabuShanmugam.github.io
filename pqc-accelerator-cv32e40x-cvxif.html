Open-Source PQC Standards Reference Implementation

Accelerator-protected ML-KEM and ML-DSA on CV32E40X + CV-X-IF (openPQC)

Post-quantum cryptography is moving into products, but the implementations being deployed are hard to compare: every paper measures a different core, a different countermeasure, a different setup. openPQC addresses that by being an open-source PQC standards reference implementation, a single open platform: the CV32E40X RISC-V core extended through the CV-X-IF coprocessor interface with custom instructions that accelerate ML-KEM (FIPS 203) and ML-DSA (FIPS 204).

The platform is accelerator-protected: side-channel countermeasures live inside the coprocessor, next to the arithmetic they protect, instead of being patched into software after the fact. Each algorithm is available in both protected and unprotected variants on the same core, so the cost and the benefit of a countermeasure can be measured directly, on identical hardware, with nothing else changing. The CV-X-IF interface keeps the CV32E40X core itself unmodified, which makes the accelerator portable and the comparison clean.

The goal is a reference implementation of the post-quantum standards that anyone can rebuild, and so an open-source reference for reproducible side-channel assessment of PQC standards. Anyone evaluating an ML-KEM or ML-DSA implementation can start from a known platform with known leakage behavior rather than building a target from scratch. The platform connects to the pre-silicon to post-silicon research line: leakage is assessed on pre-silicon models first, then validated on the physical implementation. Applied to ML-DSA-87, this top-down approach recovered key material with correlation power analysis at a minimum traces-to-disclosure of 6, and template attacks ranked the correct key in the top 10 within 50 traces.

Because the coprocessor exposes its arithmetic as an instruction set extension, the natural unit of security assessment is one custom instruction rather than one algorithm. That per-instruction view is developed in PQC custom instruction vulnerability analysis, which takes a unified ML-KEM-1024 and ML-DSA-44 coprocessor of 62 custom instructions and assesses the ten that touch a secret, pre-silicon on RTL and post-silicon on a ChipWhisperer CW305, through a bitstream flow with no vendor tool in it.

The platform is not FPGA-only. It has been taped out as PRISM, an open-source PQC reference chip in TSMC 65 nm LP running at 48 MHz: a CV32E40X core issuing 85 custom instructions over CV-X-IF to eight coprocessor banks, holding ML-KEM-1024, ML-DSA-44, SLH-DSA-128f and HQC-128 in unprotected and DOM-protected form on the same die, with one shared protected Keccak-f[1600], a Trivium mask generator, and a scan chain over all 30,301 flops for observability. Unprotected custom instructions run 3 to 41 times faster than software on the same core. PRISM taped out in September 2026 and the chips are expected in December 2026, so the side-channel evaluation of the protected coprocessors on silicon is still ahead; the assessments published so far are pre-silicon and FPGA.

openPQC is developed at the Vernam Lab, Worcester Polytechnic Institute, and released through the secure-Embedded-Systems GitHub organization.
